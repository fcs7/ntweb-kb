# IP Móvel / IP Dedicado (PUQ Mikrotik VPN)

> **Resposta rápida (40–60 palavras):**  
> **Contrate um IP fixo /32 da NTWeb** entregue via **VPN Mikrotik**, em 5 perfis: 5 Mbps (franquia 5 GB), 20 Mbps (franquia 10 GB), 10 Mbps ilimitado, 20 Mbps ilimitado e 100 Mbps ilimitado. Publique CFTV e DVR sem CGNAT, mantenha origem fixa para APIs bancárias ou faça failover de link móvel 4G/5G com IP estável.

Produtos ativos (cobrança recorrente, com **estoque controlado**):
- IP Fixo /32 — 5 Mbps D/U — 5 GB
- IP Fixo /32 — 20 Mbps D/U — 10 GB
- IP Fixo /32 — 10 Mbps D/U — Ilimitado
- IP Fixo /32 — 20 Mbps D/U — Ilimitado
- IP Fixo /32 — 100 Mbps D/U — Ilimitado

Módulo WHMCS: *PUQ Mikrotik VPN*

## Casos de uso frequentes

- Publicar CFTV/DVR na internet sem depender de CGNAT.
- IP origem fixo para APIs bancárias / liberações em firewall de terceiros.
- Failover de link com link principal móvel (4G/5G) + IP fixo via VPN.
