O que é o Coolify

O Coolify é uma plataforma open-source self-hosted que substitui serviços comerciais como Heroku, Vercel, Netlify e Render. Ele permite fazer deploy de aplicações, bancos de dados e serviços com poucos cliques, gerenciando containers Docker, certificados HTTPS automáticos via Let's Encrypt e integração contínua a partir de repositórios Git.

O Coolify é mantido pela comunidade coolify.io sob licença Apache 2.0 e tem ganhado destaque entre equipes que querem reduzir custos com PaaS comerciais sem abrir mão da praticidade do "git push e está no ar".

O que vem pronto na VPS NT

O template Coolify (VMID 5103) executa o instalador oficial do Coolify durante o primeiro boot. O instalador prepara o Docker, baixa todos os componentes do Coolify e os coloca em execução. A interface web responde na porta 8000.

Como acessar pela primeira vez

O primeiro boot leva entre três e oito minutos, pois o instalador baixa todos os contêineres do Coolify. O cliente pode acompanhar o progresso por SSH com journalctl -u app-boot -f. Quando estiver pronto, basta acessar http://<IP>:8000 — a primeira visita exibe o setup wizard.

No wizard, o cliente cadastra o usuário ROOT (e-mail e senha forte), define o domínio da instância (opcional, mas recomendado) e o e-mail de notificações. Após o setup, o painel completo está disponível e o cliente pode começar a fazer deploy de aplicações.

Casos de uso típicos

O Coolify é ideal para empresas que querem rodar várias aplicações na mesma infraestrutura sem complexidade de orquestração manual. Casos comuns incluem hospedar múltiplos sites WordPress isolados, fazer deploy de aplicações Node.js ou Python diretamente do GitHub, executar bancos PostgreSQL e Redis para vários projetos, e disponibilizar serviços auxiliares como n8n, NocoDB e Plausible Analytics em um único painel.

Equipes de desenvolvimento usam o Coolify para ter ambientes de staging completos com pipelines de deploy automático: cada push para o branch staging dispara um build e atualiza o ambiente correspondente.

Cuidados e boas práticas

O Coolify atualiza-se sozinho por padrão, e isso pode reiniciar contêineres em horários inesperados. Para cargas críticas, o cliente deve desabilitar o auto-update em Settings e fazer atualizações manualmente em janelas planejadas.

Para usar HTTPS com domínio próprio, basta configurar o domínio em Settings → Instance Domain — o Coolify gerencia o certificado Let's Encrypt automaticamente. As portas 6001 (soketi) e 6002 (terminal web) podem precisar ser liberadas no firewall caso o cliente queira usar atualizações em tempo real e o terminal interno do painel.

Perguntas frequentes

Posso hospedar quantos sites no Coolify?

Não há limite imposto pelo Coolify. O limite real é a capacidade da VPS (CPU, RAM e disco). Em uma VPS de 4 GB, é razoável hospedar entre cinco e dez aplicações pequenas.

O Coolify suporta deploy a partir do GitHub privado?

Sim. O Coolify integra-se com GitHub, GitLab e Bitbucket via tokens ou GitHub App, suportando repositórios privados sem complicação.

Como faço backup das aplicações?

O Coolify oferece backup automático para bancos de dados (PostgreSQL, MySQL) com agendamento e armazenamento em S3. Para aplicações stateless, o backup é o próprio Git. Volumes persistentes podem ser copiados manualmente ou via scripts agendados.
