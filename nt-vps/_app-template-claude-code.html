O que é o Claude Code

O Claude Code é a ferramenta de linha de comando oficial da Anthropic para usar o modelo Claude diretamente no terminal. Ele transforma a IA em um agente que lê arquivos do sistema, edita código-fonte, executa comandos shell, debuga problemas e administra servidores — tudo sob a supervisão do usuário, com confirmação a cada ação que altere o estado do sistema.

É voltado a desenvolvedores e administradores de sistemas que querem ter um assistente Claude com acesso direto ao ambiente, sem o limite de copiar e colar trechos de código entre o navegador e o editor.

O que vem pronto na VPS NT

O template Claude Code (VMID 5108) entrega Node.js 20 LTS, Git, ferramentas de build e o pacote @anthropic-ai/claude-code instalado globalmente via npm. Após o provisionamento, basta conectar via SSH na porta 2222, configurar a chave de API da Anthropic e executar claude.

Como acessar pela primeira vez

Conecte via SSH na porta 2222. Configure a chave de API exportando a variável de ambiente:

export ANTHROPIC_API_KEY="sk-ant-sua-chave-aqui"

Para tornar a configuração permanente, adicione essa linha ao final do arquivo ~/.bashrc. Em seguida, basta digitar claude em qualquer momento para iniciar uma sessão. O Claude Code lê o diretório atual, oferece edição de arquivos, execução de comandos e interação contínua até a tarefa estar pronta.

A chave de API é obtida em console.anthropic.com. O uso do Claude Code é cobrado pela API por token consumido, conforme a tabela vigente da Anthropic.

Casos de uso típicos

Desenvolvedores usam o Claude Code para implementar features completas a partir de uma descrição em linguagem natural, refatorar código legado em projetos grandes, debugar problemas que exigem leitura de múltiplos arquivos, gerar testes unitários para classes existentes e automatizar tarefas repetitivas de manutenção. Como o Claude tem acesso ao sistema de arquivos, ele consegue trabalhar em projetos completos, não apenas em trechos isolados.

Administradores de sistemas usam para diagnosticar logs complexos, escrever scripts de automação ad-hoc, configurar serviços com base em documentação interna e auditar configurações em servidores. A capacidade de executar comandos com confirmação reduz drasticamente o tempo de tarefas operacionais.

Cuidados e boas práticas

O Claude Code é um agente com capacidade de modificar arquivos e executar comandos. Cada ação destrutiva pede confirmação, mas o usuário deve revisar com atenção. Em ambientes de produção, recomenda-se rodar o Claude Code apenas em máquinas com acesso restrito e nunca como root em servidores críticos sem snapshot prévio.

O custo da API é cobrado por uso. Sessões longas e projetos grandes consomem mais tokens. A própria interface do Claude Code mostra o consumo em tempo real. A Anthropic oferece limites de gasto na conta para evitar surpresas.

Perguntas frequentes

O Claude Code é gratuito?

A ferramenta CLI é gratuita, mas exige uma chave de API da Anthropic, que é cobrada por token consumido. Há tier gratuito modesto para começar; uso pesado profissional implica em assinatura paga.

Posso usar o Claude Code em projetos confidenciais?

Sim, mas o cliente deve estar ciente de que o conteúdo dos arquivos lidos pelo Claude é enviado à API da Anthropic para processamento. A Anthropic tem políticas de não-treinamento sobre dados de clientes pagantes, mas a decisão final sobre quais arquivos compartilhar é do usuário.

Funciona offline?

Não. A inferência acontece nos servidores da Anthropic. Para ambientes sem internet, considere modelos locais via Ollama no template OpenClaw + OpenWebUI.

Onde encontro documentação oficial?

Documentação completa em docs.claude.com/claude-code.
