O que é o PaperClip

O PaperClip é uma plataforma open-source para orquestrar agentes de inteligência artificial como se fossem uma equipe corporativa. Em vez de interagir com um único modelo de IA por vez, o cliente define a missão da empresa, atribui papéis hierárquicos (CEO, CTO, engenheiro, marketing, vendas) e os agentes passam a delegar tarefas entre si por meio de tickets, todos rastreáveis em um painel único.

O projeto é mantido pela comunidade paperclipai/paperclip sob licença MIT, soma mais de 60 mil estrelas no GitHub e roda inteiramente na VPS do cliente — nenhum dado é enviado a serviços terceiros, exceto as chamadas que os próprios agentes fazem aos provedores de modelo (OpenAI, Anthropic, etc.).

O que vem pronto na VPS NT

O template PaperClip da NTWeb (VMID 5111) já vem com Node.js 20 LTS, dependências de build, banco PostgreSQL embutido e um serviço de sistema (paperclip.service) que mantém o PaperClip rodando entre reinicializações. A porta 3100 é a porta padrão da interface web. O acesso administrativo via SSH é feito pela porta 2222, não pela 22.

Como acessar pela primeira vez

Após a contratação, o painel da NTWeb provisiona automaticamente a VPS com o template selecionado. O primeiro boot leva entre três e cinco minutos, pois o servidor faz o download dos pacotes Node necessários para o PaperClip.

Durante esse intervalo, o serviço ainda não responde. O cliente pode acompanhar o progresso conectando-se via SSH e executando journalctl -u app-boot.service -f. Quando o boot conclui, o arquivo /root/credentials.txt é criado com a URL exata para acesso à interface web.

Há duas formas de acesso à interface, dependendo da configuração de domínio:

Sem domínio personalizado

O acesso é feito diretamente pelo IP da VPS, no endereço http://<IP>:3100. É a forma mais rápida para testes e ambientes internos. Não há criptografia HTTPS por padrão neste modo, então não é recomendado para uso em produção pública.

Com domínio personalizado

Se o cliente apontar um subdomínio (por exemplo, paperclip.minhaempresa.com.br) para o IP da VPS antes da contratação ou no momento do provisionamento, o template detecta o domínio automaticamente via cloud-init e exibe a URL no formato https://seudominio. Para que o HTTPS funcione, o cliente deve instalar um proxy reverso como Nginx ou Caddy na frente da porta 3100, com certificado Let's Encrypt.

Na primeira visita à interface, o PaperClip exibe a tela de cadastro inicial. O primeiro usuário criado se torna o administrador da instância. A partir daí, o cliente pode definir a missão da empresa e começar a configurar agentes e papéis.

Casos de uso típicos

O PaperClip se destaca em cenários onde múltiplas tarefas precisam ser coordenadas por agentes especializados, com supervisão humana mínima. Equipes de marketing usam o produto para gerar e revisar campanhas, com um agente "redator", outro "revisor" e um "diretor de marketing" aprovando o resultado. Times de desenvolvimento delegam tarefas como triagem de issues, geração de documentação e revisão de pull requests para agentes que se reportam a um agente "tech lead".

Em operações de negócio, o PaperClip pode atuar como um time virtual completo, com agentes representando funções como atendimento a clientes, análise financeira, geração de relatórios e prospecção de leads — todos coordenados por um agente "CEO" que recebe a missão estratégica do dono da empresa.

Cuidados e boas práticas

O PaperClip é uma plataforma poderosa e que executa chamadas pagas a APIs de modelos de IA. O cliente é responsável pelos custos dessas chamadas — a NTWeb fornece a infraestrutura, mas não cobre o consumo das APIs externas. Por isso é fundamental configurar o budget mensal por agente dentro da própria interface do PaperClip, em Settings → Budgets. Esse limite impede que um agente continue chamando o modelo após estourar o orçamento.

Para uso em produção pública, recomenda-se sempre colocar a aplicação atrás de um proxy HTTPS (Nginx ou Caddy) e configurar autenticação forte para o usuário administrador. O PaperClip não oferece TLS nativo. Backups periódicos do diretório /root/.paperclipai/ garantem a recuperação completa do estado em caso de falha.

Perguntas frequentes

Preciso ter conhecimento de programação para usar o PaperClip?

Não para o uso básico. A criação de agentes, a definição de missões e a operação cotidiana acontecem inteiramente pela interface web, sem código. Conhecimento técnico é útil apenas para integrações avançadas e personalização de habilidades dos agentes.

Quais provedores de modelo de IA o PaperClip suporta?

O PaperClip integra-se com os principais provedores comerciais (OpenAI, Anthropic, Google) e também com modelos locais via Ollama, o que permite combinar IA paga e IA gratuita conforme a sensibilidade dos dados de cada agente.

O que acontece se eu reiniciar a VPS?

O PaperClip é gerenciado pelo systemd. Após qualquer reinício, o serviço sobe sozinho e o estado anterior (agentes, conversas, tickets) é mantido pelo PostgreSQL embutido. Nenhum dado é perdido.

Posso migrar o PaperClip para outra VPS depois?

Sim. Basta copiar o conteúdo do diretório /root/.paperclipai/ para a nova VPS, instalar o template equivalente e iniciar o serviço. Os dados são portáveis.
