O que é o Gemini CLI

O Gemini CLI é a ferramenta oficial do Google para usar o modelo Gemini diretamente no terminal. É o equivalente Google ao Claude Code da Anthropic: um agente conversacional que lê arquivos, executa comandos, edita código e ajuda em tarefas administrativas, com confirmação humana a cada passo destrutivo.

O grande diferencial do Gemini CLI é o tier gratuito generoso. Com login Google pessoal, o cliente recebe uma cota mensal substancial para uso individual sem custo, o que torna a ferramenta atraente para desenvolvedores, estudantes e pequenas equipes que não querem investir em chaves de API logo de início.

O que vem pronto na VPS NT

O template Gemini CLI (VMID 5109) entrega Node.js 20 LTS, Git, ferramentas de build e o pacote @google/gemini-cli instalado globalmente via npm. Após o provisionamento, basta conectar por SSH e executar gemini.

Como acessar pela primeira vez

Conecte via SSH na porta 2222 e digite gemini. Na primeira execução, a ferramenta abre uma URL para autenticação via conta Google. O cliente abre essa URL em qualquer navegador, faz login com a conta desejada e cola o código de autorização de volta no terminal.

Para uso programático ou em scripts, é possível usar uma chave de API obtida em aistudio.google.com:

export GEMINI_API_KEY="sua-chave-aqui"

Adicionar essa linha ao ~/.bashrc persiste a configuração entre sessões.

Casos de uso típicos

Desenvolvedores usam o Gemini CLI para tarefas similares ao Claude Code: implementar features, debugar código, gerar testes, refatorar projetos. Como o tier gratuito é generoso, é especialmente popular para projetos pessoais, estudos, experimentos e prototipagem rápida.

O modelo Gemini também é forte em multimodalidade: análise de imagens, processamento de documentos PDF e tarefas que envolvem múltiplos formatos. Para times que já operam no ecossistema Google Workspace, a integração com o login da empresa torna a adoção mais simples.

Cuidados e boas práticas

Como o Claude Code, o Gemini CLI é um agente com capacidade de executar comandos e modificar arquivos. Cada ação destrutiva pede confirmação, mas o usuário deve revisar com cuidado. O conteúdo dos arquivos lidos é enviado aos servidores do Google para processamento — verifique a política de privacidade do Gemini antes de usar com dados sensíveis.

Para evitar consumo inesperado da cota, o cliente pode definir limites no Google AI Studio. Em uso corporativo, o Gemini também está disponível via Vertex AI no Google Cloud, com governança e auditoria mais robustas.

Perguntas frequentes

O Gemini CLI é realmente gratuito?

O tier gratuito é generoso para uso individual: a cota mensal cobre dezenas a centenas de interações conforme o modelo escolhido. Para uso intenso, há planos pagos via Google AI Studio ou Vertex AI.

Qual a diferença entre Gemini CLI e Claude Code?

São ferramentas equivalentes em conceito, cada uma usando o modelo da empresa que a desenvolve. A escolha depende da preferência por modelo (Gemini do Google vs Claude da Anthropic), do tier gratuito (Gemini é mais generoso para começar) e da integração desejada (Gemini com Workspace, Claude com Anthropic Console).

Posso ter os dois templates ao mesmo tempo?

Sim. Como cada template é uma VPS independente, o cliente pode contratar uma VPS Claude Code e outra Gemini CLI em paralelo, ou usar uma única máquina e instalar manualmente o segundo CLI no template do primeiro.
