O que são Ollama e OpenWebUI

O Ollama é um servidor que roda modelos de linguagem (LLMs) localmente, sem necessidade de enviar dados a serviços externos. Ele suporta dezenas de modelos open-source, como Llama 3, Mistral, DeepSeek, Phi, Gemma, Qwen e variantes especializadas em código (CodeLlama, DeepSeek-Coder).

O OpenWebUI é uma interface web parecida com o ChatGPT, mas que se conecta ao Ollama em vez de a uma API externa. Combinados, os dois oferecem uma experiência de IA conversacional 100% privada — todas as perguntas, anexos e respostas ficam apenas na VPS do cliente.

O que vem pronto na VPS NT

O template Ollama + OpenWebUI (VMID 5102) traz os dois serviços em contêineres Docker, com a interface web exposta na porta 3000. O Ollama escuta apenas em loopback por segurança — todo o acesso é mediado pelo OpenWebUI.

Como acessar pela primeira vez

O cliente acessa http://<IP>:3000 e é direcionado à tela de cadastro. O primeiro usuário a se cadastrar se torna o administrador da instância. A partir do painel, é possível ir em Settings → Models e baixar modelos sob demanda, ou usar o terminal SSH para executar ollama pull llama3.

Modelos pequenos (3 a 7 bilhões de parâmetros) rodam aceitavelmente em CPU. Modelos maiores (13B, 30B, 70B) exigem GPU dedicada para tempo de resposta razoável. Para cargas profissionais, recomenda-se VPS com GPU NVIDIA.

Casos de uso típicos

O combo Ollama + OpenWebUI é ideal para empresas que precisam usar IA generativa sem expor dados sensíveis a APIs externas. Cenários comuns incluem: análise de contratos jurídicos sem enviar texto ao ChatGPT, atendimento interno em empresas com NDA rígido, geração de código com CodeLlama em projetos confidenciais, e geração de documentação técnica com modelos especializados.

Para uso pessoal, o cliente pode ter um "ChatGPT particular" que respeita 100% da privacidade, sem cota de uso, sem censura excessiva e sem custo recorrente por token.

Cuidados e boas práticas

Modelos de IA local consomem muita RAM e disco. Cada modelo de 7B ocupa aproximadamente 4 a 8 GB de armazenamento. Antes de baixar vários modelos, o cliente deve dimensionar o disco da VPS adequadamente. O OpenWebUI também armazena histórico de conversas — backup periódico do volume Docker é recomendado.

Em redes públicas, o cliente deve sempre colocar HTTPS na frente do OpenWebUI (Nginx ou Caddy com Let's Encrypt). A interface por padrão está em HTTP, e logins de usuários trafegam em texto claro caso não haja TLS.

Perguntas frequentes

Preciso de GPU para usar?

Não obrigatoriamente. Modelos de até 7B parâmetros rodam em CPU com tempo de resposta entre 10 e 60 segundos por mensagem. GPU melhora drasticamente a velocidade, especialmente em modelos maiores.

Posso usar com modelos comerciais como GPT-4 ou Claude?

Sim. O OpenWebUI também suporta conexões a APIs externas (OpenAI, Anthropic, Google) configuradas em Settings → Connections. O cliente pode misturar modelos locais e modelos pagos no mesmo painel.

Quais modelos recomendados para começar?

Llama 3.1 (8B) para uso geral, Mistral Nemo (12B) para tarefas mais elaboradas, DeepSeek-Coder (6.7B) para programação. Todos rodam em CPU com VPS de 8 a 16 GB de RAM.
