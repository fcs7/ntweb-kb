O que é o combo OpenClaw + OpenWebUI

Este template combina três ferramentas de inteligência artificial em uma única VPS: o OpenClaw (assistente de IA via terminal, similar em conceito ao Claude Code), o Ollama (servidor de modelos LLM locais) e o OpenWebUI (interface web tipo ChatGPT). O resultado é um ambiente completo onde o cliente usa IA tanto via SSH (no terminal) quanto via navegador, com modelos locais ou APIs comerciais.

É a configuração ideal para profissionais que querem ter à disposição múltiplas formas de interagir com IA sem precisar provisionar várias VPSs.

O que vem pronto na VPS NT

O template OpenClaw + OpenWebUI (VMID 5107) instala o Ollama nativo (não em contêiner, para ter acesso direto ao hardware) e sobe o OpenWebUI via Docker Compose. O OpenClaw é instalado como pacote npm global e fica disponível como comando no terminal.

Como acessar pela primeira vez

O acesso à interface web acontece em http://<IP>:3000. O primeiro usuário cadastrado torna-se administrador da instância. A partir do painel, é possível ir em Settings → Models e baixar modelos via interface. Modelos também podem ser baixados pelo terminal SSH com ollama pull llama3.

Para usar o OpenClaw via terminal, o cliente conecta por SSH na porta 2222 e executa openclaw onboard uma única vez. O wizard pede a chave de API do provedor desejado (Anthropic, OpenAI ou outros) e configura integrações com ferramentas locais. Depois, basta digitar openclaw em qualquer momento para iniciar uma sessão.

Casos de uso típicos

O combo é ideal para times que mantêm múltiplos modelos e precisam de ambientes de IA flexíveis. Casos comuns: revisão de código sensível com modelos locais (sem expor o código a APIs externas), geração de relatórios e análises com Claude/GPT via OpenWebUI, automação de tarefas administrativas com OpenClaw no terminal (gerenciamento de servidores, geração de scripts ad-hoc), e treinamento interno de colaboradores em uso de IA — todos os modelos disponíveis em um único endereço.

Cuidados e boas práticas

O Ollama nativo escuta em 0.0.0.0:11434 por padrão neste template, para que o OpenWebUI possa se conectar. Em redes públicas, recomenda-se restringir essa porta no firewall para apenas o loopback ou para hosts específicos. O OpenWebUI deve ficar atrás de HTTPS (Nginx ou Caddy) em qualquer cenário público.

Modelos LLM locais ocupam espaço considerável em disco — entre 4 e 40 GB cada, dependendo do tamanho. Antes de baixar vários modelos, verifique o disco da VPS. As chaves de API armazenadas pelo OpenClaw ficam em ~/.openclaw/ e devem ser tratadas como senhas: nunca compartilhe esse diretório em backups públicos.

Perguntas frequentes

Posso usar apenas a interface web e ignorar o OpenClaw?

Sim. As três ferramentas são independentes. O cliente pode usar apenas o OpenWebUI, apenas o OpenClaw, ou os dois conforme a conveniência.

Como conecto a interface web a um modelo da OpenAI?

Em Settings → Connections do OpenWebUI, adicione uma nova conexão tipo OpenAI e cole sua chave de API. O modelo aparece automaticamente na lista de seletores de modelo do chat.

O OpenClaw funciona offline?

Apenas se configurado para usar modelos locais via Ollama. Para modelos em nuvem (Claude, GPT), é necessário acesso à internet.
