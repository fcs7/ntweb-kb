O que é o Zabbix

O Zabbix é uma das plataformas open-source mais maduras e adotadas no mundo para monitoramento de infraestrutura de TI. Ele coleta métricas de servidores, redes, aplicações, bancos de dados, dispositivos SNMP e qualquer fonte de dados que possa ser consultada. Com base nessas métricas, o Zabbix gera dashboards, alertas em tempo real e relatórios de SLA.

É usado por empresas de todos os portes — desde pequenas equipes monitorando dezenas de máquinas até operadoras de telecom monitorando centenas de milhares de elementos de rede. O projeto é mantido pela empresa Zabbix LLC e oferecido sob licença AGPL, com suporte comercial opcional.

O que vem pronto na VPS NT

O template Zabbix (VMID 5106) sobe o servidor Zabbix completo via Docker Compose: o frontend web, o servidor Zabbix, o banco MySQL e o agente local. A interface web responde na porta 80. A senha do MySQL e do usuário Admin do Zabbix são geradas automaticamente no primeiro boot e gravadas em /root/credentials.txt.

Como acessar pela primeira vez

Acesse http://<IP>/ ou http://<DOMINIO>/ caso tenha configurado um. A tela de login pede usuário e senha. O usuário é Admin (com A maiúsculo) e a senha está em /root/credentials.txt. Caso a senha não tenha sido trocada automaticamente, o sistema usa a senha padrão zabbix, que deve ser trocada no primeiro acesso.

Após o login, o painel inicial mostra o status do próprio servidor Zabbix. A partir daí, o cliente cadastra hosts a serem monitorados, instala agentes Zabbix nas máquinas-alvo e configura templates (conjuntos prontos de itens, gatilhos e gráficos) para Linux, Windows, MySQL, Nginx e dezenas de outras plataformas.

Casos de uso típicos

O Zabbix é usado para monitorar disponibilidade de servidores web, latência de APIs, espaço em disco em servidores de arquivos, temperatura de switches gerenciáveis via SNMP, métricas de bancos de dados (queries lentas, conexões abertas, replicação), e até processos de negócio (número de pedidos novos por minuto, transações financeiras pendentes).

Provedores de internet usam Zabbix para monitorar OLTs, switches e roteadores. Empresas SaaS o utilizam para alertar a equipe de plantão quando uma API começa a apresentar latência anormal, antes que clientes reclamem.

Cuidados e boas práticas

O banco de dados do Zabbix cresce rapidamente em ambientes com muitos hosts e itens. Configure políticas de housekeeping (retenção) adequadas para evitar enchimento de disco. Para grandes volumes, considere usar TimescaleDB ou Elastic em vez do MySQL padrão.

Alertas só são úteis se chegam a quem precisa agir. Configure mídias (e-mail, Telegram, Slack, webhook) e ações (escalonamento, horários de plantão) logo no início. Templates da comunidade em zabbix.com/integrations aceleram bastante a configuração inicial.

Perguntas frequentes

Quantos hosts posso monitorar nesta VPS?

Em uma VPS de 4 GB de RAM, com configuração padrão, é razoável monitorar entre 100 e 300 hosts com checagens a cada minuto. Para volumes maiores, considere aumentar RAM, otimizar o MySQL e usar partitioning das tabelas históricas.

Como instalo o agente Zabbix em uma máquina remota?

Use os pacotes oficiais do zabbix.com/download. Em Debian/Ubuntu, basta apt install zabbix-agent e configurar o IP do servidor no arquivo /etc/zabbix/zabbix_agentd.conf.

Tem app móvel?

Sim, o Zabbix oferece app oficial para iOS e Android, além de aplicativos da comunidade. Os apps consultam a API do servidor e exibem alertas e dashboards no celular.
