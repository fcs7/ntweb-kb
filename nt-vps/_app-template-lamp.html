O que é o stack LAMP

LAMP é a sigla clássica para Linux + Apache + MariaDB + PHP — a combinação de software livre que sustenta a maior parte da web mundial. É a fundação de plataformas como WordPress, Joomla, Drupal, Magento, PrestaShop e milhares de aplicações corporativas em PHP.

O nome "MariaDB" entra no lugar do tradicional "M" de MySQL porque o MariaDB é o sucessor open-source independente do MySQL, mantido pelos criadores originais do projeto. Ele é totalmente compatível com aplicações que esperam MySQL.

O que vem pronto na VPS NT

O template LAMP da NTWeb (VMID 5104) já entrega o stack instalado, configurado e iniciado. O Apache responde na porta 80, o MariaDB tem senha de root gerada no primeiro boot (disponível em /root/credentials.txt) e os módulos PHP mais usados pelas plataformas populares já vêm instalados.

Como acessar pela primeira vez

O acesso administrativo é via SSH na porta 2222. A senha de root do MariaDB está em /root/credentials.txt e é usada para criar bancos e usuários para cada aplicação.

Para hospedar um site, basta colocar os arquivos em /var/www/html/. Esse é o DocumentRoot padrão do Apache. Acesse http://<IP>/ e a página de teste do Apache (ou seu próprio index.php) será exibida.

Casos de uso típicos

O LAMP é a escolha natural para hospedar sites WordPress, sistemas legados em PHP, instalações corporativas como Magento, Moodle (ensino a distância), Joomla, Drupal e CMS personalizados. Empresas que migram de hospedagem compartilhada para VPS encontram no template LAMP exatamente o ambiente que já estavam acostumadas a usar.

Desenvolvedores também usam o LAMP como ambiente de homologação espelho do servidor de produção, garantindo paridade de versões PHP e MariaDB entre os ambientes.

Cuidados e boas práticas

O Apache vem com configuração padrão. Para múltiplos sites na mesma VPS, o cliente deve criar virtual hosts em /etc/apache2/sites-available/ e habilitá-los com a2ensite. Para HTTPS, o caminho recomendado é instalar o Certbot (certbot.eff.org) e gerar certificados Let's Encrypt automáticos.

O backup mínimo recomendado é despejar bancos com mysqldump e copiar o conteúdo de /var/www/html/. Para automatizar, scripts de cron podem rodar diariamente e enviar os arquivos a um storage externo. Senha do root MariaDB nunca deve ser compartilhada — para aplicações, crie usuários dedicados com privilégios apenas no banco específico.

Perguntas frequentes

Posso instalar WordPress nesta VPS?

Sim. Basta baixar o WordPress, descompactar em /var/www/html/, criar um banco MariaDB e seguir o instalador web. Todo o stack necessário já está configurado.

Como ativo HTTPS?

Instale o Certbot com apt install certbot python3-certbot-apache e execute certbot --apache -d seudominio.com.br. O Certbot gera o certificado, configura o Apache e renova automaticamente.

Qual a diferença entre LAMP e LEMP?

O "A" é Apache; o "E" (de Engine-X) é Nginx. Apache é mais flexível para regras .htaccess e plugins WordPress; Nginx é mais leve e rápido em sites de alto tráfego. Ambos hospedam as mesmas aplicações PHP.
