## Convenções

- **Idioma:** português (pt-BR), ortografia correta com acentos.
- **Formato:** Markdown. Prints em `_midia/` (PNG) e vídeos como link/embed.
- **Slug:** numerado `NN-kebab-case.md` para manter ordem de leitura.
- **Placeholders:** `TODO` marca trechos que dependem de informação externa (roteador, módulo, prazo etc.).
- **Público:** cada tutorial tem seção leiga (PF) + seção técnica (PJ).
