Resumo: há três jeitos de colocar seu site no ar: instalar o WordPress em poucos cliques, enviar os arquivos pelo gerenciador de arquivos do Plesk ou usar o FTP com o FileZilla. Os arquivos públicos ficam sempre na pasta httpdocs.

Abrir a Área do Cliente

Troque seudominio.com.br pelo domínio do seu site. Os endereços deste artigo usam seudominio.com.br como exemplo. Se o seu site é lojadamaria.com.br, onde aparecer seudominio.com.br você usa lojadamaria.com.br.

Qual caminho escolher

WordPress

Você ainda não tem site e quer montar um com temas e plugins. A instalação é automática.

Arquivos prontos

Seu site já existe (feito por um profissional ou em outra hospedagem). Envie os arquivos pelo Plesk ou por FTP.

Onde fica tudo

  1. Acesse novo.ntweb.net.br e entre com seu login.
  2. Abra Meus Serviços e clique no seu plano de hospedagem.
  3. No menu da esquerda, em Manage Account (gerenciar conta), estão as ferramentas deste artigo.
  4. No grupo One Click Login há atalhos que abrem Backup Manager, Plesk, Webmail e WP Toolkit já logados, sem pedir senha de novo.

Instalar o WordPress

  1. No menu Manage Account, clique em WordPress Toolkit. (Outro caminho: One Click Login > WP Toolkit.)
  2. Clique no botão New Installation (nova instalação). No Plesk, o mesmo recurso fica no menu WordPress.
  3. Preencha o formulário: o domínio, a pasta de instalação, o usuário e a senha do administrador do WordPress e o idioma.
  4. Confirme e aguarde a instalação terminar.

Ao terminar, o site aparece na lista do WordPress Toolkit, com as colunas Name (nome), URL e Version (versão do WordPress). Pelo endereço da coluna URL você acessa o site e, adicionando /wp-admin ao final, o painel do WordPress.

Anote o usuário e a senha do administrador. Você precisa deles para entrar no painel do WordPress. Eles não são os mesmos da Área do Cliente.

Outros aplicativos

Em Manage Account > Applications você vê os aplicativos instalados no plano. A tela tem duas abas: Applications (aplicativos) e Backups (cópias de segurança dos aplicativos; veja "Backup e restauração").

Enviar arquivos pelo Plesk

Bom para sites pequenos ou ajustes rápidos, sem instalar nada no computador.

  1. No grupo One Click Login, clique em Plesk.
  2. No Plesk, abra Websites e Domínios.
  3. No cartão do seu domínio, clique em Gerenciador de arquivos em httpdocs. (Outro caminho: menu Arquivos.)
  4. Dentro da pasta httpdocs, use o botão de upload (ícone "+") para enviar os arquivos do site.

A pasta httpdocs

Tudo o que fica dentro de httpdocs é o que as pessoas veem quando abrem seudominio.com.br. Regras simples:

  • A página inicial deve se chamar index.html ou index.php e ficar direto dentro de httpdocs, não em uma subpasta.
  • Se você enviar uma pasta inteira (por exemplo, meusite/), o site passa a ficar em seudominio.com.br/meusite/. Envie o conteúdo da pasta, não a pasta.
  • Instalações do WordPress feitas pelo WP Toolkit já ficam no lugar certo. Não mexa nos arquivos do WordPress por FTP sem necessidade.

Não apague a pasta httpdocs nem arquivos que você não reconhece. Apagar os arquivos do WordPress tira o site do ar. Se tiver dúvida, faça um backup antes.

Enviar arquivos por FTP (FileZilla)

Ideal para sites grandes ou para quem atualiza com frequência. Use FTPS (FTP com TLS explícito): é o FTP com criptografia, e protege sua senha.

1. Criar a conta FTP

  1. Na Área do Cliente, abra o plano em Meus Serviços.
  2. No menu Manage Account, clique em FTP Access.
  3. Clique em Create Account (criar conta) e defina o nome de usuário e uma senha forte.

A lista mostra suas contas com as colunas Name (usuário) e Path (pasta que essa conta acessa).

2. Conectar no FileZilla

Campo O que digitar
Servidor (host) seudominio.com.br, ou o IP do servidor mostrado na página do serviço
Porta 21
Protocolo FTP, com criptografia: Exigir FTP explícito sobre TLS
Usuário e senha os que você criou em FTP Access
  1. No FileZilla, abra o Gerenciador de Sites e crie um novo site com os dados da tabela.
  2. Clique em Conectar. Na primeira vez, o FileZilla mostra o certificado do servidor: confirme e marque para confiar.
  3. No painel da direita (servidor), entre em httpdocs. No painel da esquerda (seu computador), selecione os arquivos e arraste para a direita.

Atenção ao usuário e à pasta. A coluna Path em FTP Access mostra a pasta inicial da conta. Se não encontrar httpdocs, confira essa coluna.

Evite o FTP sem criptografia. Selecionar "usar FTP simples" envia a senha às claras pela internet. Use sempre FTP explícito sobre TLS.

O plano de hospedagem não tem acesso SSH. Para enviar arquivos, use o FTP ou o gerenciador de arquivos do Plesk.

Criar um banco de dados

Sites feitos em PHP, como o WordPress, guardam textos e configurações em um banco de dados. O WP Toolkit já cria o banco sozinho. Crie manualmente só se a instalação do seu sistema pedir.

  1. No menu Manage Account, clique em Databases. A tela tem duas abas: Databases (os bancos) e Users (os usuários do banco).
  2. Clique em Create Database (criar banco) e dê um nome.
  3. Um banco precisa de um usuário com permissão para usá-lo. Crie o usuário e a senha na aba Users e dê a ele permissão no banco.
  4. Anote o nome do banco, o usuário e a senha. O sistema que você instala vai pedir esses três dados, além do host do banco.

Em aplicativos instalados na própria hospedagem, use localhost como host. No Plesk, Bancos de dados > Adicionar banco de dados cria o banco já com um usuário, e Informação de Conexão (no Painel do domínio) mostra os valores exatos.

Ver o conteúdo do banco (phpMyAdmin)

  1. No grupo One Click Login, clique em Plesk.
  2. Abra a área de Bancos de Dados do seu domínio e clique em phpMyAdmin.

Cuidado no phpMyAdmin. Apagar tabelas ou linhas não tem "desfazer". Faça um backup antes de qualquer alteração.

Perguntas frequentes

Enviei os arquivos mas o site não aparece

Confira se a página inicial (index.html ou index.php) está direto dentro de httpdocs. Confira também se o domínio já aponta para a hospedagem. Se acabou de mudar o DNS, a propagação pode levar até algumas horas.

O FileZilla não conecta

Confira a porta (21), o usuário e a senha criados em FTP Access e se o protocolo está em FTP explícito sobre TLS. Se o domínio ainda não aponta para a hospedagem, use o IP do servidor, que aparece na página do serviço, em vez do domínio.
