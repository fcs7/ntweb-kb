# NTFONE — VoIP / VPBX (4PSA VoipNow)

> **Resposta rápida (40–60 palavras):**  
> **NTFONE é a telefonia VoIP da NTWeb**, sobre 4PSA VoipNow. Use o **Plano Básico** (residencial, 1 ramal) ou **Escritório Virtual 5R, 10R, 20R ou 30R** (empresarial) para distribuir ramais, montar IVR, gravar chamadas e contratar DID próprio. Configure softphone no celular (Zoiper) ou telefone IP físico (Grandstream, Yealink). Saldo via recargas 4PSA Credit.
